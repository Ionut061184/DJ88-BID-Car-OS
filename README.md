# DJ 88 BID Car OS

Proiect Android pentru interfața DJ 88 BID la rezoluția 1280×720, pe navigația QF001/K706.

## Situație

Acest depozit este separat de AI Gardian. Themes original și firmware-ul QF001 **nu se modifică**. Nu se instalează APK-uri modificate de sistem fără verificarea semnăturilor și a metodei de recuperare.

**Stadiu:** inițializarea depozitului. Codul Android v1.4 există în arhiva de lucru, dar nu este încă transferat integral aici; resursele grafice aprobate trebuie încărcate înainte de compilare. Nu există deocamdată un APK verificat.

## Obiectiv

APK instalabil ca launcher separat, cu posibilitatea de revenire la launcherul original și testarea individuală a tuturor comenzilor (GPS, Bluetooth, Telefon, YouTube, Setări, Aplicații). Funcțiile de radio, DSP, tensiune auto și integrarea Themes sunt neconfirmate și nu trebuie prezentate drept funcționale.
