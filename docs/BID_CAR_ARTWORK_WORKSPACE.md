# BID 360 artwork workspace
Separate private artwork library for six future still images: top, front, rear, both sides, three-quarter. Native Android document picker, user-selected content URI, no general storage permission; validated PNG/JPEG/WebP up to 16 MiB, 8192 px per side and 40 MP; original bytes preserved, sampled preview, atomic replacement, explicit delete confirmation. Empty slots show no fabricated artwork. Entry under Funcții > Mașină > Model DJ 88 BID. No changes to approved home artwork, OEM Birdview assets, calibration, camera feed, licensing or firmware. This is an independent preview/import tool, not a native 3D model importer. Model geometry/texture format and permissible OEM integration remain to be investigated. Also fixes compile regression in Bridge.open(command) reported in run 45765973291 (unresolved action). Tests are static contracts; Android compile and actual USB picker behavior remain unverified.

## Export de referințe și format 3D confirmat din APK-ul original
Audit direct BirdviewHD_ZR.apk: în assets/vrbackcarapp/model/ există 15 directoare de modele, fiecare cu model.gltf (asset.version 2.0), buffer extern .bin, texturi PNG și newcarmodel.txt; modelarr.txt enumeră directoarele. Fișierele .bin observate sunt aproximativ 2,1–4,2 MB, modelele au 51–69 mesh-uri și 11–16 materiale. Unele texturi OEM referă ../logo.png, deci viitorul model BID va trebui să aibă resurse proprii și să fie verificat separat. Nu se presupune că imaginile 2D sunt suficiente pentru geometria 3D. Nu se modifică sau distribuie modelele OEM. Atelierul BID exportă acum un ZIP cu imaginile originale (sloturi stabile, extensii detectate), manifest JSON cu dimensiuni și SHA256, utilizând ACTION_CREATE_DOCUMENT. Exportul nu este firmware, nu este importabil nativ în Birdview și nu afectează calibrarea. Scrierea eșuată la destinație poate lăsa un fișier incomplet, dar nu modifică originalele. Testele sunt contracte de sursă; compilarea și document picker rămân de verificat.
