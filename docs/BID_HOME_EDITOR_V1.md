# BID Home editor v1
User-selected full screen artwork PNG/JPEG/WebP exactly 1280x720, maximum 16 MiB. Native preview overlays the 23 audited hit rectangles from index.html without changing event handlers or actual touch coordinates. Explicit Apply saves normalized PNG atomically to private storage. Restore deletes only custom artwork; packaged bid_fullbleed.png and bid_approved.png unchanged. WebView serves the single image through a strictly scoped intercepted HTTPS URL, no network fallback for that host. Live status, clock, dock and safety overlays remain unchanged. No new storage permission. Functions > Personalizare BID > Editor ecran principal. This is a full-composite replacement, not free movement of controls or separate layer editing; the input artwork must align with the fixed zones, and the preview is a visual alignment aid, not a real-time simulation of live status overlays. Actual rendering and document picker on the QF001 require verification. Separate icon and background editing for the Functions drawer remains available. No firmware modification.

## Individual graphic regions v1.1
Nine opt-in areas: central artwork and eight media/navigation tiles. Source: approved 1280x720 composite and its 23 hit rectangles. Each user-selected image is decoded with size limits and scaled proportionally (10–100% of fit), horizontally/vertically positioned, clipped to its selected region and previewed. The complete composite is rendered only after "Verifică ecranul"; existing full-screen preview and explicit Apply persist it atomically. No touch event or geometry changes; central region does not intersect any existing hit target, each tile patch fits within exactly one hit target; adjacent dock overlaps excluded. Edits flatten into the current composite; not a persistent editable layer stack and no separate extraction of baked icons/car from original. Transparent patches can leave original pixels visible; complete replacement tiles should include the correct label. Original packaged artwork remains available via restore. No new permissions. Static tests verify region containment; real device display/gestures unverified.
