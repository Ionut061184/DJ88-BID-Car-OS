# BID Theme Profiles v1
Preserves legacy working profile (slot 0) and adds five independent editable slots. Save current appearance into an empty slot, activate an existing slot, delete inactive slots only, export current slot, import into an empty slot. Home composite, drawer palette, background and eight cosmetic icons only. No OEM/MCU, permissions, user app associations, personal data, 360 calibration or artwork reference library are included. ZIP manifest schema 1 kind BID_THEME, SHA256 per image (integrity, not authorship). Reject unknown or duplicate paths, directory entries, invalid PNG geometry, unsupported palette, oversized decompressed content or mismatched hash; stage files under app-private storage and publish only after validation. No overwrite of saved themes. Legacy paths/palette preferences retained. Storage chooser uses explicit user action, no broad permissions. Failed external export can leave an incomplete destination file. Source-level tests verify contracts; build and device tests pending. Theme slots use numbered names in v1. Original packaged artwork remains available via each editor's restore action.
