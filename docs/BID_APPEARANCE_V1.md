# BID appearance v1
Optional customization of native Functions drawer only. Default exact gradient, title and dot colors preserved; four palettes, local user-picked background and eight non-safety-critical shortcut icons. Native document picker, request codes 560–568, no broad storage access. Import validates PNG/JPEG/WebP, max 16 MiB/8192 per side/40MP, downscales to 1280/256, stores PNG atomically in private app storage. Original source files remain untouched. Dark scrim for background; no change to touch targets, routes, home artwork, camera/calibration, reference images or OEM files. Restore one asset or all drawer customizations. Reopen drawer to see changes; no APK rebuild needed after installation. UI/Android tests still required; static contract tests do not establish actual runtime behavior. Full home customization deferred because approved composite image and coordinate hit zones need separate validation.
